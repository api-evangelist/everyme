# everyme

everyme was surfaced as a portfolio company of slow-ventures and added to the API Evangelist network as a stub for enrichment.

**Status: defunct — no operating company surface (checked 2026-07-20).**

Enrichment probing found that `everyme.com` no longer resolves to a company website. It redirects (HTTP 307) to a GoDaddy aftermarket listing offering the domain for sale, its nameservers are Afternic (a domain broker), and its DNS publishes a null MX record with an SPF policy of `v=spf1 -all`. `docs.everyme.com` and `api.everyme.com` do not resolve.

There is no developer portal, documentation, API, or event surface to catalog. This profile is retained as a historical lead record rather than an active provider.
